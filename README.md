**TikTok View Bot v5.0** là phiên bản **MAX SPEED** - được tối ưu để tăng view TikTok với tốc độ cao nhất có thể. Hỗ trợ cả 2 chế độ:

- **Chế độ Selenium** - Giả lập trình duyệt thật (view chất lượng cao)
- **Chế độ Requests** - Gửi request nhanh (tốc độ tối đa)

## 🔧 HƯỚNG DẪN CÀI ĐẶT

### Bước 1: Cài đặt Python
- Tải tại: https://www.python.org/downloads/
- **Tích chọn "Add Python to PATH"**
- Click "Install Now"

### Bước 2: Tạo thư mục
```cmd
mkdir C:\TikTokBot
cd C:\TikTokBot
```

Bước 3: Tạo các file

File bot.py - Copy từ phần code bên dưới

File run.bat - Copy từ phần code bên dưới

Bước 4: Cài đặt Chrome (nếu dùng Selenium)

· Tải Chrome: https://www.google.com/chrome/
· Cài đặt Chrome

Bước 5: Cài đặt Chromedriver (nếu dùng Selenium)

· Mở Chrome, vào chrome://settings/help xem version
· Tải Chromedriver: https://chromedriver.chromium.org/downloads
· Giải nén chromedriver.exe vào C:\Windows\System32

Bước 6: Chạy bot

· Double-click vào run.bat
· Hoặc mở CMD: cd C:\TikTokBot -> python bot.py
